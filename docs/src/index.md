# HostWise.jl: AirBnB Price Estimator 

## Description of Project 
The project will use data in order to estimate the daily price range and potential annual revenue range for AirBnB users or hosts in the European city of Athens. It will do so by taking various inputs from users regarding amount of beds, bedrooms, bathrooms, amenities and location of apartment to estimate the price range they should expect to pay if they are an AirBnB user and the price they can charge if they are an AirBnB host. Additionally, for AirBnB hosts, their expected annual revenue can also be analysed by using occupancy rate estimates from existing AirBnB's to calculate an interval. Other variables, including reviews, room type, number of occupants, and super-host status will be considered to make the estimates even more accurate. 

## Dataset 
For the dataset, the data from " https://insideairbnb.com/get-the-data/ " will be used. This website provides detailed data regarding AirBnB listings in various cities including the one mentioned previously. The datasets are provided as CSV files making it easier to import into and manipulate the resulting DataFrame in the Julia REPL These datasets provide information access to various variables which relevant to our project and helpful in improving the accuracy as well as reliability of our model. These variables include but are not limited to the ones mentioned earlier. Given the extensive amount of data available for various cities on this website, it makes the model replicable for multiple cities globally, which is a potential way to expand upon the project in the future.

## Functions
The underlying function used is a regression model created through a regression constructed using the variables explained in the preceding sections. Based on this regression equation, we can estimate an exact price point at which the model estimates the price of an AirBnB. To improve the accuracy of results, the model uses other syntax including `predict()` from the GLM package to provide an estimate for an interval within which the actual price is expected to lie. Given this prediction, we can also determine whether or existing AirBnB's are considered overpriced, adequately priced, or underpriced. By multiplying this price estimation by the estimated occupancy over the last year, we can also estimate the potential revenue a host can earn with their AirBnB. 

## Ultimate Goal 
As already explained in the functions section, the ultimate goal is to provide valuable data to users wanting to either rent an AirBnB or put their apartment or house on the market as an AirBnB. Given this goal and the different functions described early, the data needed for this project, which was also described earlier, does not need to be time-series data. The data provided is cross-sectional data, which is appropriate given that our goal is not to provide AirBnB pricing at specific points throughout the year, but rather just identifying the overall price interval that would be appropriate.
